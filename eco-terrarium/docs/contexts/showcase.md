## 4. 규칙과 불변 조건

- **프리셋은 관찰 가능한 결과를 보장한다.** 돌연변이 폭발 프리셋은 매 실행 5초 이내에 새 종을 해금한다.
- **프리셋은 분화 규칙 자체를 건드리지 않는다.** 환경과 초기 조건만 바꾼다.
- **프리셋은 현재 환경에서 실제로 해금 가능한 종을 고른다.**
- **프리셋으로 재시드하면 이전 온도 이력이 초기화된다.**

## 5. 의존 방향

- 의존하는 곳: `ecosystem`(엔진 공개 API), `i18n`.
- 이 컨텍스트에 의존하는 곳: `app`.
