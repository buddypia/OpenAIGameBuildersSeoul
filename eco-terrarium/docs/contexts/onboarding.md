# `onboarding` SPEC

최종 확인: 2026-08-30 · 공개 입구: `src/features/onboarding/index.ts`

## 1. 책임

처음 들어온 플레이어가 설명 없이도 무엇을 만지면 되는지 알게 한다.

**소유한다**: 시작 화면, 플레이 가이드 모달, 첫 이해에 필요한 안내 흐름.
**소유하지 않는다**: 실시간 생태 안내 문구의 판단. `ecosystem`의 `getEcosystemAdvice`가 소유한다.

## 2. 소유 요구사항

| ID | 요구 | 구현 위치 |
| --- | --- | --- |
| NFR-UX-02 | 직관적인 툴팁 및 온보딩 가이드 | `presentation/StartScreen.tsx`, `presentation/HelpGuideModal.tsx` |

가이드 모달은 FR-HIVE-04의 **테라리움 초기화 확인 절차**도 담는다. 초기화 자체는 `hive`와 `ecosystem`이 수행한다.

## 3. 공개 계약

| 종류 | 이름 | 용도 |
| --- | --- | --- |
| 컴포넌트 | `StartScreen` | 첫 진입 화면 |
| 컴포넌트 | `HelpGuideModal` | 플레이 가이드와 초기화 확인 |

## 4. 규칙과 불변 조건

- **초기화는 확인 절차 없이 실행되지 않는다.** 저장본 폐기·재시드·해금 초기화가 한 번에 일어나는 되돌릴 수 없는 조작이다.
- **온보딩은 플레이를 막지 않는다.** 언제든 건너뛰고 닫을 수 있다.
- **모든 안내 문구는 3개 언어 카탈로그에 있다.**

## 5. 의존 방향

- 의존하는 곳: `i18n`, `hive`(초기화 호출).
- 이 컨텍스트에 의존하는 곳: `app`.
