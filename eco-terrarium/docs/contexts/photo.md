# `photo` SPEC

최종 확인: 2026-08-30 · 공개 입구: `src/features/photo/index.ts`

## 1. 책임

플레이어가 마음에 드는 순간을 이미지로 남겨 밖으로 가져가게 한다.

**소유한다**: 스냅샷 캡처, 필터 적용, 워터마크, 다운로드.
**소유하지 않는다**: 캔버스 렌더링 자체(`ecosystem`), 배속 제어의 시뮬레이션 반영(`ecosystem`의 엔진). 배속 UI는 `app`이 합성한다.

## 2. 소유 요구사항

| ID | 요구 | 구현 위치 |
| --- | --- | --- |
| FR-PROG-03 | 0.5x/1x/2x/5x 배속과 일시정지, 필터(빈티지·네온·수채화) 및 워터마크 포함 스냅샷 다운로드 | `presentation/PhotoModal.tsx` (사진), `src/app/App.tsx` + `ecosystem` 엔진 (배속·일시정지) |

> FR-PROG-03은 두 곳에 걸친다. **사진 모드는 이 컨텍스트가 소유하고, 시간 제어는 `ecosystem` 엔진이 소유한다.** 배속을 바꾸는 작업은 `ecosystem` SPEC의 "일시정지 중 상태 불변" 불변 조건을 확인한다.

## 3. 공개 계약

| 종류 | 이름 | 용도 |
| --- | --- | --- |
| 컴포넌트 | `PhotoModal` | 촬영·필터·다운로드 화면 |

## 4. 규칙과 불변 조건

- **촬영은 시뮬레이션을 바꾸지 않는다.** 읽기 전용 캡처다.
- **다운로드 실패가 게임을 멈추지 않는다.** 브라우저가 다운로드를 막아도 조용히 실패한다.
- **워터마크는 항상 포함된다.**

## 5. 의존 방향

- 의존하는 곳: `ecosystem`(캔버스 참조), `i18n`.
- 이 컨텍스트에 의존하는 곳: `app`.
