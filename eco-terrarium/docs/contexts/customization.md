# `customization` SPEC

최종 확인: 2026-08-30 · 공개 입구: `src/features/customization/index.ts`

## 1. 책임

플레이어가 자기 테라리움의 겉모습을 고르게 한다. 순수하게 표시에만 영향을 준다.

**소유한다**: 선택 가능한 유리병·바닥재·배경 목록과 선택 UI.
**소유하지 않는다**: 실제 렌더링. `ecosystem`의 `TerrariumRenderer`가 선택 결과를 소비한다.

## 2. 소유 요구사항

| ID | 요구 | 구현 위치 |
| --- | --- | --- |
| FR-PROG-02 | 유리병 4종, 바닥 토양 4종, 배경 4종 선택 | `presentation/CustomizationModal.tsx` |

## 3. 공개 계약

| 종류 | 이름 | 용도 |
| --- | --- | --- |
| 컴포넌트 | `CustomizationModal` | 커스터마이징 선택 화면 |

## 4. 규칙과 불변 조건

- **커스터마이징은 시뮬레이션에 영향을 주지 않는다.** 같은 시드·같은 조작이면 겉모습과 무관하게 같은 생태 결과가 나온다.
- **해금되지 않은 파츠는 선택할 수 없다.** 해금 판정은 `progression`이 소유한다.
- **선택 항목의 문구는 `i18n` 카탈로그에서 온다.**

## 5. 의존 방향

- 의존하는 곳: `progression`(해금 상태), `i18n`.
- 이 컨텍스트에 의존하는 곳: `app`, 렌더링 소비자로서의 `ecosystem`.

수동 확인: 각 파츠를 선택했을 때 캔버스에 즉시 반영되는지, 해금 전 파츠가 잠겨 있는지, 선택이 저장·복원되는지.

## 7. 변경 시 주의

- 파츠를 추가하면 `i18n` 3개 언어 문구와 `ecosystem` 렌더러의 대응 처리를 함께 추가한다.
- 파츠 식별자를 저장본이 참조한다면 id를 안정적으로 유지한다.
