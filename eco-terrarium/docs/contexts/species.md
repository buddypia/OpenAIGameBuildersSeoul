# `species` SPEC

최종 확인: 2026-08-30 · 공개 입구: `src/features/species/index.ts`

## 1. 책임

플레이어가 무엇을 발견했고 무엇이 남았는지 보여주고, 개체 하나를 현미경으로 들여다보게 한다.

**소유한다**: 도감의 표시 규칙(발견/미발견, 실루엣과 힌트), 진화 계통도 표시, 개체 인스펙터의 표시 항목.
**소유하지 않는다**: 종 데이터의 원본과 분화 판정. 이는 `ecosystem`의 `INITIAL_SPECIES_DATABASE`와 `checkSpeciation`이 소유하며 이 컨텍스트는 소비만 한다.

## 2. 소유 요구사항

| ID | 요구 | 구현 위치 |
| --- | --- | --- |
| FR-BIO-01 | 15종 이상의 도감(학명·프리뷰·설명·서식 조건), 미발견은 실루엣과 힌트 — **현 빌드 16종** | `presentation/EncyclopediaModal.tsx` |
| FR-BIO-02 | 개체 클릭 시 포커싱 UI: 이름 변경, 나이, 유전자 세부 수치, 세대, 섭취 기록 | `presentation/InspectorModal.tsx` |

## 3. 공개 계약

| 종류 | 이름 | 용도 |
| --- | --- | --- |
| 컴포넌트 | `EncyclopediaModal` | 도감과 진화 계통도 |
| 컴포넌트 | `InspectorModal` | 현미경 개체 관찰 |

## 4. 규칙과 불변 조건

- **인스펙터는 선언된 유전자 전부를 표시한다.** 표시 항목 수와 `shared/kernel/types.ts`의 `Genome` 필드 수가 어긋나면 안 된다(현행 10차원, `DEC-004`).
- **미발견 종은 정보를 노출하지 않는다.** 실루엣과 해금 힌트만 보인다.
- **종 정보의 문구는 `i18n`의 `getSpeciesText`에서 온다.** 컴포넌트에 한국어를 직접 쓰지 않는다.

## 5. 의존 방향

- 의존하는 곳: `ecosystem`(공개 API로 종 데이터·개체 상태), `i18n`(`getSpeciesText`), `shared/kernel`.
- 이 컨텍스트에 의존하는 곳: `app`.

## 7. 변경 시 주의

- Genome 차원이 바뀌면 인스펙터 표시를 함께 고친다. 라벨만 고치면 표시와 선언이 어긋난 채 남는다.
- 종을 추가하면 `ecosystem`의 `INITIAL_SPECIES_DATABASE`, `i18n`의 3개 언어 종 문구, FR-BIO-01의 종 수 서술을 함께 갱신한다.
