# 제출 가이드라인 (Submission Guidelines)

OpenAI Game Builders Seoul의 온라인 예선(Track 1) 및 현장 본선(Track 2) 제출에 관한 요구사항, 필수/선택 항목, 계정 인증 및 폼 입력 상세 안내입니다.

---

## 1. 제출 기본 원칙 및 자격

1. **단일 계정 / 구글 로그인 기반**: 참가 신청 및 제출은 구글(Google) 계정 로그인을 통해 진행됩니다. 로그인한 이메일로 수상 및 본선 안내가 전달됩니다.
2. **팀 대표자 1인 제출**: 팀 단위(최대 3인)로 참가하더라도 대표자 1인이 신청서를 작성하고 제출합니다.
3. **복수 작품 제출 허용**: 1인의 참가자(또는 팀)가 여러 개의 서로 다른 작품을 제출할 수 있습니다. 단, **본선 진출 및 최종 수상은 1인당 최대 1개 작품만 가능**하며, 복수 작품이 상위권일 경우 가장 높은 점수를 받은 1개 작품만 선정됩니다.
4. **수정 제출 가능**: 접수 기간 중 변경 사항이 발생하면 수정된 최신 버전으로 다시 제출할 수 있습니다. 운영진은 **가장 마지막에 제출된 최종본을 기준으로 심사**합니다.

---

## 2. 제출 형식 및 링크 요구사항 (중요)

### ✅ 허용되는 형태 (반드시 준수)
- **웹 브라우저에서 즉시 실행되는 플레이 가능한 웹 링크 (URL)**
- HTML5, Canvas, WebGL, WebGPU, WebAssembly(Wasm), Three.js, Phaser, Pixi.js, Unity WebGL, Godot Web, Unreal HTML5 등 브라우저 기반 빌드
- 호스팅 플랫폼 예시: Vercel, Netlify, Cloudflare Pages, GitHub Pages, Itch.io (HTML5 Playable), 자체 도메인 등

### ❌ 심사 대상에서 제외되는 형태 (절대 불가)
- **모바일/PC 설치 파일 다운로드 링크** (.apk, .ipa, .exe, .dmg, .zip 등)
- **소스코드 저장소 링크만 제출** (GitHub, GitLab 등 단순 리포지토리)
- **게임을 플레이할 수 없는 단순 소개/개발 블로그 페이지**
- **로그인 또는 유료 결제가 필수로 요구되는 게임** (심사위원이 계정 생성이나 결제 없이 즉시 플레이 가능해야 함)
- **심사 기간 중 접속이 불가능하거나 서버가 다운된 링크**

```
⚠️ 링크 유의사항 요약
1. 심사 기간(2026.08.27 전후) 동안 24시간 접속 가능 상태를 유지해야 합니다.
2. 별도 승인이나 접근 권한 요청 없이 즉시 접속 가능해야 합니다.
3. 조작법(키보드/마우스/터치 등)이 게임 화면 내에 명확히 안내되어야 합니다.
```

## 3. 신청서 상세 입력 항목

신청 폼은 크게 4개 섹션으로 구성됩니다.

```
┌─────────────────────────────────────────────────────────────┐
│ 01. 신청 전 확인 (개인정보, 동의서, 국가/생년월일)         │
├─────────────────────────────────────────────────────────────┤
│ 02. 참가 신청자 인적 사항 (이름, 팀명, 연락처, 본선참석여부)│
├─────────────────────────────────────────────────────────────┤
│ 03. 프로젝트 필수 제출 (제목, 소개, 플레이 링크, 썸네일)    │
├─────────────────────────────────────────────────────────────┤
│ 04. 추가 자료 선택 제출 (데모 영상 링크, Codex 활용기)      │
└─────────────────────────────────────────────────────────────┘
```

### 섹션 1: 신청 전 확인
- **수상 시 연락받을 이메일**: 현재 로그인한 Google 계정 자동 연결 (계정 변경 가능)
- **대표자 거주 국가**: 국가 목록 검색 및 선택 (필수)
- **참가 약관 동의**: 약관 전문 확인 후 동의 (필수)
- **개인정보 수집·이용 동의**: 전문 확인 후 동의 (필수)
- **개인정보 국외 이전 동의**: 대한민국/미국(OpenAI, Google) 이전 확인 (해당 시 필수)
- **생년월일 입력**: 연도, 월, 일 선택 (거주국 아동 보호 기준 적용)
- **법정대리인 동의서**: 미성년자의 경우 법정대리인 성명, 관계, 연락처, 이메일 입력 및 동의 (필수)

### 섹션 2: 참가 신청자 인적 사항
- **성명 (필수)**: 대표 신청자 실명 (최대 100자)
- **팀명 (필수)**: 외부에 공개되는 닉네임/팀 이름 (최대 40자)
- **소속 (선택)**: 회사, 대학교, 동아리 등 (최대 150자)
- **오프라인 본선 참석 가능 여부 (필수)**: 예 / 아니오
- **긴급 연락처 (필수)**: 전화번호 (국제 표준 E.164 형식)
- **행사 운영 안내 수신 여부 (필수)**: 동의 / 비동의

### 섹션 3: 프로젝트 제출 (필수)
- **게임 제목 (필수)**: 최종 공식 게임명 (최대 80자)
- **게임 소개 (필수)**: 핵심 재미와 콘셉트 요약 (최대 200자 이내)
- **플레이 가능한 게임 링크 (필수)**: `https://` 형태의 웹 플레이 URL (최대 2,048자)
- **게임 썸네일 이미지 (필수)**: 16:9 비율 권장, JPG/PNG, 최대 10MB

### 섹션 4: 추가 자료 제출 (선택 / 가산점 부여)
- **데모 영상 링크 (선택)**: 3분 이내 YouTube, Vimeo 등 영상 링크 (게임소개/실제 플레이/핵심기능 포함)
- **Codex 활용 과정 설명 (선택)**: 최대 5,000자 이내
  - *질문 가이드*:
    1. Codex를 어디에 어떻게 사용했나요?
    2. Codex로 어떤 핵심 기능을 구현했나요?
    3. 개발 중 어떤 문제를 Codex로 해결했나요?
    4. 사람이 직접 판단하고 결정/개발한 부분은 무엇인가요?

---

## 4. 기존 프로젝트 활용 규정

- 기존에 개발 중이던 프로젝트나 에셋을 기반으로 발전시켜 출품하는 것도 **가능합니다.**
- 다만, 기존 프로젝트를 활용한 경우에는 **해커톤 챌린지 기간 동안 새롭게 개발된 기능과 내용(Codex 활용 내역 포함)을 신청서에 명확히 기재**해야 합니다.
